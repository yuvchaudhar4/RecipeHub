RecipeHub - recipe sharing platform (Admin and User roles)

Fastest way (no install): double-click index.html. It opens in Chrome and runs fully.

Run with the Java server (Java 11 or newer):
  javac RecipeHubServer.java
  java RecipeHubServer
Then open http://localhost:8080 in Chrome. Data is saved in data.json.
